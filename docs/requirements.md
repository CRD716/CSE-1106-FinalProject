## Project Requirements
The functional requirements are as follows: logs interactions with the entry and exit buttons, as well as events, to a file; maintains and displays the current occupancy count in the terminal; by default, sets minimum occupancy to 0 and maximum occupancy to 5; displays current status and occupancy in the terminal, as well as utilizes an LED for maximum status; and provides the function of altering max occupancy count. All components are combined to create a functioning and simple tool for study room occupancy status.
